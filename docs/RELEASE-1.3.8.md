# Snapir Design X 1.3.8 — Snapshot

## Every project on the home screen, not the newest three

The home screen showed three project cards. Import a fourth and one dropped
off the end, which reads exactly like the older project having been lost — and
nothing on that screen said otherwise.

Nothing ever was lost: the full list has always been one tap away under All
projects, and the backend has always returned every project. The cap was only
ever how many cards the home screen drew.

It draws all of them now, most recently opened first. The grid already wraps,
so a long list costs nothing but scrolling.
