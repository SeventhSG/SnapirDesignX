Native type, not web type

The interface uses the platform's own face, so it reads as a Windows application rather than a page. Every measurement is set in tabular-nums so digits line up down a column.

Motion you don't notice

Hover and selection settle in 130 ms, screens in 190 ms, all on one easing curve. Nothing pulses, nothing bounces, and every transition has a reduced-motion path.

It asks, it never guesses

Where the survey is ambiguous the room states what is missing in one sentence. It will not invent a corner or a ceiling height.
